## Política de Privacidade

Última atualização: 19 de novembro de 2026.

**Quem somos.** O FNANDO Publicador é uma ferramenta interna do canal FNANDO. Ela roda só no computador do dono do canal e não tem usuários externos.

**Quais dados acessamos.** Com a autorização do próprio dono (login do Google via OAuth), a ferramenta usa a YouTube Data API para:
- enviar vídeos ao canal FNANDO e colocá-los nas playlists do canal;
- ler as estatísticas públicas do próprio canal e dos próprios vídeos (inscritos, visualizações, curtidas e comentários).

A ferramenta não acessa, não coleta e não armazena dados de outros usuários do YouTube, nem de quem assiste aos vídeos.

**Onde os dados ficam.** Os tokens de acesso e os números do canal ficam só no computador do dono, num arquivo protegido. Nada é vendido, compartilhado ou enviado a terceiros.

**Serviços do Google.** O uso de dados recebidos das APIs do Google segue a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado. A ferramenta usa os Serviços de API do YouTube e, por isso, também segue os [Termos de Serviço do YouTube](https://www.youtube.com/t/terms) e a [Política de Privacidade do Google](https://policies.google.com/privacy).

**Como revogar o acesso.** O acesso pode ser removido a qualquer momento em [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Ao revogar, a ferramenta para de enviar e de ler dados, e os tokens guardados deixam de funcionar e são apagados.
